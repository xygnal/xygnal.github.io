# |t|=1  →  Re(s)=1/2

Let t = exp(j\*w) where 0<=w<2pi.

    s = 1/{ e(jw)+1 }
    = e(-jw/2) / { e(jw/2)+e(-jw/2) }
    = {cos(w/2) - j*sin(w/2) } / { 2*cos(w/2) }
    = 1/2 -j*tan(w/2)/2

    i.e.  Re(s) = 1/2

# Re(s)=1/2  →  |t|=1

Let s = 1/2 + jy where real y.

    |t| = |1/s - 1| = |1/(1/2 + jy) - 1|
    =  | 2(1 -j 2y)/(1 + 4y^2) - 1|
    = | (2 - j 4y -1 - 4y^2)/(1 + 4y^2) |
    = | (1 - 4y^2 - j 4y) | /(1 + 4y^2)
    = sqrt( {1 - 4y^2}^2 + 16y^2)  /(1 + 4y^2)
    = sqrt( {1 + 4y^2}^2 )  /(1 + 4y^2)
    = 1

# So, |t|=1  ↔  Re(s)=1/2

when s=1/(t+1) in ℂ domain.

NB.  **|t| = r  is transformed to  |s + 1/(r^2 -1)| = r/|r^2 -1|**

Let t = r\*exp(j\*w) where 0<=w<2pi.

    s + 1/(r^2 -1) = 1/{ r*e(jw)+1 } + 1/(r^2 -1)
    = { r^2 -1 + r*e(jw)+1 } / { r*e(jw)+1 } / (r^2 -1)
    = r/(r^2 -1)  *  { r + e(jw) }/{ r*e(jw)+1 }
    And
    | { r + e(jw) }/{ r*e(jw)+1 } |
    = | { r+cos(w) + j*sin(w) }/{ rcos(w)+1 + j*rsin(w) } |
    = sqrt{ r^2 + 1 + 2rcos(w) } / sqrt{ r^2 + 1 + 2rcos(w) }
    = 1
    So,
    | s + 1/(r^2 -1) | =  r/|r^2 -1|

    1) r<1,  1/2< 1/(1+r) <= Re(s) <= 1/(1-r)          so, Re(s) ≠ 1/2
    2) r>1,       1/(1-r) <= Re(s) <= 1/(1+r) < 1/2    so, Re(s) ≠ 1/2
